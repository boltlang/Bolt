# Getting started

## Installing Bolt

Bolt isn't packaged yet, so you build it from source. You need
[Rust](https://www.rust-lang.org/tools/install) and Git:

```bash
git clone https://github.com/boltlang/Bolt.git
cd Bolt
cargo install --path crates/boltlang-cli
```

This installs the `bolt` command. Check that it works:

```bash
bolt --version
```

## The standard library

Bolt has a small standard library, `std`, which gives every file some names
without importing them, like `print`, `Option`, `Some` and `None`. This set
of names is called the *prelude*.

`std` comes with the compiler, so there's nothing to set up. The first time
`bolt` runs, it puts the files of `std` where you can read them, in a
directory for its version, which `bolt --version` shows:

```bash
bolt --version
```

```text
bolt 0.2.0
std: /home/you/.local/share/bolt/0.2.0-18bd2315615a79c2/std (comes with the compiler)
```

The files are read-only: editing them would change `std` for every program.
To work on `std` itself, see [Packages](../internals/packages.mdx).

## Your first program

Create a file called `hello.bolt`:

```bolt title="hello.bolt"
print("Hello, world!");
```

and run it:

```bash
bolt run hello.bolt
```

```text
Hello, world!
```

A Bolt file is a list of statements, which run from top to bottom. Every
statement at the top level of a file ends with a `;`.

`bolt run` also prints the value of the last statement, if it has one. So a
file that ends with `1 + 2;` prints `3`. The examples in this tutorial use
that to show their result.

## Checking for errors

`bolt run` checks a program before running it, and doesn't run it if it finds
errors. You can also check a file without running it:

```bash
bolt check hello.bolt
```

No output means no errors. Try a program with a mistake in it:

```bolt title="oops.bolt"
let x: Bool = 1;
```

```text
[E0201] Error: expected `Bool`, found an integer
   ╭─[ oops.bolt:1:15 ]
   │
 1 │ let x: Bool = 1;
   │        ──┬─   ┬
   │          ╰─────── expected because of this annotation
   │               │
   │               ╰── expected `Bool`, found an integer
───╯
```

Bolt points at the mistake, and at the code that made it a mistake.

## Editor support

The repository has a language server, `bolt-language-server`, which shows
errors as you type, and a Vim plugin in `vim-bolt`.
