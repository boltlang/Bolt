scores[2] += 5;

Changing a field of a mut struct
:todo wasm
================================================================================
struct Point { x: i32, y: i32 }
let p = mut Point { x: 0, y: 0 };
p.x = 5;
p.y += 2;
p;
--------------------------------------------------------------------------------
