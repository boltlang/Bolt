================================================================================
Instances are generic in rows of effects
================================================================================

fn twice[E](f: fn() does E) does E { f(); f() }
fn hello() does Log { log(1); }
fn both[E](f: fn() does E) does Log + E { twice(f); twice(hello) }
fn quiet() {}
fn run(f: fn() does Log) = match f() { () => (), effect log(x), k => resume(k, ()) };
run(|| { both(hello); both(quiet) });
--------------------------------------------------------------------------------

  -> both with imm rows Log
